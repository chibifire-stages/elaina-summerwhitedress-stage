# chibifire-stages

The cleaned OpenUSD stage of **Elaina - The Witch's Journey (Summer White Dress)**
by [ScarletJadeDream](https://sketchfab.com/ScarletJadeDream), CC-BY-4.0: the
model's FBX converted to OpenUSD, cleaned, named to one convention, and split into
a layer stack.

| path | what it is |
|---|---|
| `elaina-clean/Elaina_clean.usda` | the stage — open this file |
| `elaina-clean/layers/` | the rig, the materials, the camera and light, and one layer per geometry family |
| `elaina-clean/textures/` | the images |
| `tools/` | the pipeline that produced it, and the checks |
| `docs/` | the naming convention, the layer layout, what changed |

    usdview elaina-clean/Elaina_clean.usda
